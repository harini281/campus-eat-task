# CampusEats Task Tracker

CampusEats Task Tracker is a simple project created for SE3090 Lab 08.

## Features

- Manage CampusEats tasks
- Practice Git branching
- Use GitHub Pull Requests
- Track work using GitHub Issues
- Run automated checks using GitHub Actions CI

## Project Structure

- `src/tasks.js` - Contains the CampusEats task list.
- `.github/workflows/ci.yml` - Contains the GitHub Actions CI workflow.

## Purpose

This project is used to practice Git, GitHub, CI/CD, code quality, and security concepts.
